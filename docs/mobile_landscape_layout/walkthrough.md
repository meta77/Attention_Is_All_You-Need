# スマートフォン横画面向けレイアウト調整結果

## 変更内容
スマートフォン横画面（画面幅 `md`：768px以上付近）において、3つの主要要素（解説、マップ、データテンソル）が横に並ぶようにレイアウトを調整しました。

### [MODIFY] [index.html](file:///Users/horokusa/Desktop/atention/index.html)
- **グリッドの変更**:
  - `grid-cols-1 lg:grid-cols-12` を `grid-cols-1 md:grid-cols-12` に変更し、スマートフォン横画面（`md`）から12カラムの横並びレイアウトが適用されるようにしました。
- **カラム幅の割り当て**:
  - 左側（解説）: `md:col-span-3`
  - 中央（マップ）: `md:col-span-4` (マップの視認性確保のためやや広め)
  - 右側（データ）: `md:col-span-5`
- **縮小調整**:
  - 中央のアーキテクチャ・マップがスマートフォンの幅に収まるよう、`md:scale-[0.65]` を追加し、表示領域を超えないように調整しました。

## 確認事項
開発者ツール（Device Mode）等で、横画面（例: 幅 800px 程度）にした際に、3つのセクションが横に並び、アーキテクチャマップが適切なサイズで収まっているかを確認してください。右側のデータテンソル部分は横スクロールで内容が確認できます。
