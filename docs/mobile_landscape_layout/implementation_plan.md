# スマートフォン横画面向けレイアウト調整

スマートフォン横画面時（おおよそ 640px 〜 900px の画面幅）に、「現在の処理ユニット」「アーキテクチャ・マップ」「データテンソル」の3つの要素を横並びに配置するためのUI改善計画です。

## 課題と現状
現在は、画面幅が `lg` (1024px) 以上の場合のみ横に3つ並び、それ以下（スマートフォンの縦・横画面を含む）では全て縦に積まれる（1カラム）設計になっています。
このため、スマートフォンの横画面ではスクロール量が多くなり、全体の流れを一覧しにくい状態です。

## Proposed Changes

### [コンポーネント: メインレイアウト]

#### [MODIFY] [index.html](file:///Users/horokusa/Desktop/atention/index.html)
- **グリッドレイアウトのブレイクポイント変更**: 
  - 親コンテナのクラスを `grid-cols-1 lg:grid-cols-12` から、スマートフォンの横画面（`sm` または `md` サイズ）を考慮したクラスに変更します。
  - 例: `grid-cols-1 sm:grid-cols-12` または Flexbox に変更し、スマートフォンの横画面で横並びを強制・許可する。
- **カラム幅の調整**: 
  - スマホ横画面（例: `sm` ブレイクポイント）において、画面幅が限られているため、各要素のサイズやスケール（`scale` クラス）を調整し、潰れずに表示できるようにします。
  - 左（解説）: 3カラム分、中央（マップ）: 3カラム〜4カラム分、右（テンソル）: 5カラム〜6カラム分といった比率を `sm:col-span-X` で適用します。
- **要素の縮小表示**: 
  - スマートフォン横画面では絶対的な幅が足りないため、「アーキテクチャ・マップ」や「データテンソル」の中身がはみ出さないように `scale` クラス（例: `sm:scale-75` など）やフォントサイズの微調整を追加し、画面に収まるようにします。
  - データテンソル部分は `overflow-x-auto` を維持・強化し、横スクロールで見られるようにします。
